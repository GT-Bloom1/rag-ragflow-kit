# 第一章 机器学习基础

## 1.1 什么是机器学习

机器学习是人工智能的一个分支，研究如何让计算机从数据中自动学习规律，并利用学到的规律对新数据做出预测或决策。与传统编程不同，传统编程由人写出规则，机器学习则由算法从样本中归纳规则。一个机器学习系统通常包含三个要素：数据、模型和学习算法。数据提供经验，模型决定可以表达的规律范围，学习算法负责在模型空间中寻找最符合数据的参数。

按照训练数据是否带有标签以及反馈方式的不同，机器学习通常分为监督学习、无监督学习、半监督学习和强化学习四大类。本课程重点讲授前两类，强化学习只在第六周做概览介绍。

## 1.2 监督学习

监督学习使用带标签的训练数据，每个样本都由输入特征和对应的正确输出组成。模型的目标是学习从输入到输出的映射函数。当输出是离散类别时，任务称为分类，例如判断一封邮件是否为垃圾邮件；当输出是连续数值时，任务称为回归，例如根据房屋面积和位置预测房价。

常见的监督学习算法包括线性回归、逻辑回归、决策树、随机森林、支持向量机和神经网络。逻辑回归虽然名字里有“回归”，但它实际上是一种分类算法，通过 Sigmoid 函数把线性组合映射为 0 到 1 之间的概率。

## 1.3 无监督学习

无监督学习使用没有标签的数据，目标是发现数据内部的结构。典型任务包括聚类、降维和异常检测。聚类把相似的样本分到同一组，K-means 是最常用的聚类算法，它需要事先指定簇的数量 K。降维把高维数据压缩到低维空间，主成分分析（PCA）通过寻找方差最大的投影方向来保留尽可能多的信息。

监督学习和无监督学习的核心区别在于训练数据是否有标签：监督学习有明确的“标准答案”可以计算误差，无监督学习只能依据数据本身的分布和相似性来学习。

## 1.4 过拟合与欠拟合

过拟合是指模型在训练集上表现很好，但在未见过的测试集上表现明显变差，原因是模型把训练数据中的噪声也当成了规律。欠拟合则是模型过于简单，连训练集上的规律都没有学到。判断方法是同时观察训练误差和验证误差：训练误差低而验证误差高通常意味着过拟合，两者都高通常意味着欠拟合。

缓解过拟合的常用方法有：增加训练数据、降低模型复杂度、使用 L1 或 L2 正则化、提前停止训练以及数据增强。其中 L2 正则化也称为权重衰减，它在损失函数中加入参数平方和的惩罚项，使权重趋向于较小的值。

## 1.5 模型评估

为了客观评估模型，数据通常被划分为训练集、验证集和测试集，本课程推荐的划分比例是 7:1.5:1.5。训练集用于拟合参数，验证集用于调整超参数和选择模型，测试集只在最后使用一次，用于报告最终性能。

当数据量较少时可以使用 K 折交叉验证：把数据分成 K 份，轮流用其中一份做验证、其余 K-1 份做训练，最后取 K 次结果的平均值。课程实验中统一使用 5 折交叉验证。

分类任务的常用指标包括准确率、精确率、召回率和 F1 分数。精确率衡量预测为正的样本中有多少真的为正，召回率衡量真正为正的样本中有多少被找了出来。F1 分数是精确率和召回率的调和平均数，适合在类别不平衡时使用。
