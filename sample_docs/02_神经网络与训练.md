# 第二章 神经网络与训练方法

## 2.1 从感知机到多层网络

感知机是最简单的神经网络，它对输入做加权求和，再通过阶跃函数输出 0 或 1。单层感知机只能解决线性可分问题，无法表示异或（XOR）运算。把多个神经元按层堆叠，并在层与层之间使用非线性激活函数，就得到了多层感知机（MLP）。理论上，含有一个足够宽隐藏层的网络可以逼近任意连续函数，这一结论称为万能逼近定理。

常用的激活函数有 Sigmoid、Tanh 和 ReLU。ReLU 的定义是 max(0, x)，计算简单，并且在正区间梯度恒为 1，因此能缓解深层网络中的梯度消失问题，是目前隐藏层的默认选择。

## 2.2 损失函数

损失函数衡量模型预测值与真实值之间的差距。回归任务通常使用均方误差（MSE），分类任务通常使用交叉熵损失。交叉熵损失与 Softmax 输出层配合使用，可以把网络输出解释为各类别的概率分布。

## 2.3 反向传播与梯度下降

神经网络的训练方法是“前向计算损失、反向传播梯度、更新参数”的循环。反向传播算法利用链式法则，从输出层开始逐层计算损失对每个参数的偏导数。得到梯度以后，梯度下降法沿着梯度的反方向更新参数，更新公式为：新参数 = 旧参数 − 学习率 × 梯度。

根据每次更新使用的样本数量，梯度下降分为三种：批量梯度下降每次使用全部样本，结果稳定但速度慢；随机梯度下降（SGD）每次只用一个样本，速度快但波动大；小批量梯度下降每次使用一小批样本，是实践中最常用的方式。本课程实验默认的批大小（batch size）是 64。

## 2.4 学习率与优化器

学习率决定每一步参数更新的幅度。学习率太大，损失会震荡甚至发散；学习率太小，收敛非常缓慢。常见做法是先用较大的学习率快速下降，再逐步衰减，这种策略称为学习率调度，例如余弦退火和阶梯衰减。

Adam 优化器结合了动量法和 RMSProp 的思想，为每个参数维护梯度的一阶矩和二阶矩估计，从而自适应地调整学习率。Adam 的默认学习率通常设为 0.001，课程实验二要求同学们比较 SGD 与 Adam 在 MNIST 数据集上的收敛速度。

## 2.5 正则化与训练技巧

Dropout 是一种专门用于神经网络的正则化方法：训练时以概率 p 随机将部分神经元的输出置零，迫使网络不依赖少数神经元，从而减轻过拟合；推理时关闭 Dropout。课程推荐的 Dropout 概率是 0.5。

批归一化（Batch Normalization）对每一层的输入做标准化处理，使其均值接近 0、方差接近 1，可以加快训练速度并允许使用更大的学习率。权重初始化同样重要，使用 ReLU 时推荐 He 初始化，使用 Tanh 时推荐 Xavier 初始化。

## 2.6 卷积神经网络简介

卷积神经网络（CNN）主要用于图像任务。卷积层通过共享权重的小卷积核在图像上滑动提取局部特征，池化层降低特征图的分辨率并增加平移不变性。经典的 CNN 结构包括 LeNet、AlexNet、VGG 和 ResNet。ResNet 引入了残差连接，让信号可以跳过若干层直接传递，从而能够训练上百层的深度网络。
