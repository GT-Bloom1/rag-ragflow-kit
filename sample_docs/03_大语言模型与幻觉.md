# 第三章 大语言模型与模型幻觉

## 3.1 Transformer 与自注意力

大语言模型几乎都基于 Transformer 架构。Transformer 的核心是自注意力机制：序列中的每个位置都会计算与其他所有位置的相关程度，并据此加权汇总信息。具体做法是把输入映射为查询（Query）、键（Key）和值（Value）三组向量，用查询与键的点积除以维度的平方根得到注意力分数，经过 Softmax 归一化后再对值向量加权求和。多头注意力把这一过程并行执行多次，让模型在不同子空间中关注不同类型的关系。

由于自注意力本身不包含顺序信息，Transformer 需要额外加入位置编码。早期使用正弦位置编码，现在的大模型多采用旋转位置编码（RoPE）。

## 3.2 预训练、微调与对齐

大语言模型的训练一般分为三个阶段。第一阶段是预训练，模型在海量无标注文本上做“预测下一个词”的任务，学习语言知识和世界知识。第二阶段是指令微调（SFT），使用人工编写的“指令—回答”数据让模型学会遵循指令。第三阶段是对齐训练，例如基于人类反馈的强化学习（RLHF）或直接偏好优化（DPO），使模型的回答更符合人类偏好，更有帮助、更安全。

参数高效微调方法可以只训练少量参数。LoRA 在原有权重旁边加入两个低秩矩阵，只训练这两个小矩阵，显著降低了显存需求。

## 3.3 什么是模型幻觉

模型幻觉（Hallucination）是指大语言模型生成了看似流畅、可信，但与事实不符或没有依据的内容，俗称“模型编造答案”。例如，模型可能虚构一篇并不存在的论文，或者给出错误的历史日期，并且语气非常肯定。

幻觉产生的原因主要有：预训练数据中存在错误或过时的信息；模型的知识截止于训练时间，无法知道之后发生的事情；模型的训练目标是生成概率最高的下一个词，而不是保证事实正确；当问题超出模型掌握的知识范围时，模型倾向于“补全”一个答案而不是承认不知道。

## 3.4 减少大模型幻觉的方法

减少大模型幻觉的方法可以从数据、模型和应用三个层面入手。在应用层面，最常用、成本最低的方法是检索增强生成（RAG）：先从可靠的知识库中检索与问题相关的资料，再把资料和问题一起交给模型，要求模型依据资料作答并给出引用来源。这样模型回答时有据可查，用户也能核对原文。

其他方法还包括：在提示词中明确要求“资料中没有答案时回答不知道”；降低生成温度（temperature），减少随机性；让模型分步推理并自我检查；对关键领域使用经过审核的数据继续微调；在输出后接入事实核查模块。需要注意，RAG 只能减少而不能完全消除幻觉，如果检索到的资料本身不相关或不完整，模型仍然可能出错。

## 3.5 上下文窗口

上下文窗口是模型一次能够处理的最大 token 数量，包括输入和输出。窗口越大，可以放入的检索资料越多，但计算成本也越高，而且模型对长上下文中间部分的信息利用率往往较低，这一现象被称为“中间迷失”（Lost in the Middle）。因此在 RAG 系统中，检索结果并不是越多越好，通常只选取最相关的 3 到 8 个片段。
